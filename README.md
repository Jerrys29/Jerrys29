## 🌟 Projets Phares

### 🎙️ [TonsoTranslator](https://github.com/Jerrys29/TonsoTranslator)
> Traducteur intelligent pour les francophones — accède au meilleur contenu anglophone (éducatif, humoristique, informatif) sans barrière de langue.
- **Stack :** TypeScript · IA · NLP
- **Problème résolu :** Des millions de francophones ratent du contenu de qualité faute de traduction adaptée
- **Statut :** 🟢 Actif

---

### 📰 [NewsGuard](https://github.com/Jerrys29/NewsGuard)
> PWA avancée d'agrégation de news avec vérification et filtrage intelligent.
- **Stack :** TypeScript · PWA · API REST
- **Fonctionnalités :** Progressive Web App, lecture hors-ligne, notifications
- **Statut :** 🟢 Actif

---

### 📈 [Trading Journal](https://github.com/Jerrys29/trading-journals)

- **Statut :** 🟡 En maintenance
